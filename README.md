# rock-paper-scissors
A Rock, Paper, Scissors game built in Python with score tracking, input validation, and a computer opponent.

## Features

- Player vs. computer mode
- Custom victory goal
- Score tracking
- Input validation
- Random computer choices
- Replay option

## How to Play

1. Run the Python program.
2. Choose how many victories are needed to win.
3. Choose Rock, Paper, or Scissors.
4. The computer will randomly choose its move.
5. The first player to reach the victory goal wins.

- Random module
